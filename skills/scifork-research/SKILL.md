# SciFork Research (M0 stub)

SciFork Research turns retrieval results already present in the Chat context
into a `Research Import Draft`, plans simulations, and critiques the research
graph. The full instruction set lands with M3; this M0 stub exists so the
bundled skill is discoverable and loadable in sequence after a retrieval skill.

- Never call another Skill.
- Never write Research Project files directly.
- Persistence goes through SciFork typed tools after user confirmation.
